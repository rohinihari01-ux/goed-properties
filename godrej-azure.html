About Godrej Azure

Project overview Padur · OMR · Chennai
Contemporary homes in a connected location

Godrej Azure is a premium residential apartment project by Godrej Properties, located in Padur, OMR. Spread across 6.22 acres, the project features thoughtfully designed 2 & 3 BHK apartments with unit sizes ranging from 1,000 sq. ft. to 1,455 sq. ft. With 167 residential units across Stilt + 18 floors, Godrej Azure is designed to offer contemporary living in a well-connected location. The project is currently under construction, with possession expected in December 2028.
